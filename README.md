# Ethiora

Connecting Ethiopia Through Commerce.

Ethiora is a modern Ethiopian online marketplace built with React, FastAPI, and PostgreSQL.

## Tech Stack

- React
- Vite
- Tailwind CSS
- FastAPI
- PostgreSQL
- SQLAlchemy
- JWT Authentication

## Features

- Product Search
- Category Filter
- Shopping Cart
- Wishlist
- Seller Dashboard
- Admin Dashboard
- Secure Authentication
- Order Management
- Ethiopian Payment Integration
